# Module simbot-api

Simple Robot 核心 API 定义模块，定义 Bot、事件、消息、组件等核心抽象。

# Package love.forte.simbot.ability

行为能力定义，如发送、回复、删除等能力接口。

# Package love.forte.simbot.application

Application 抽象定义与工厂实现。

# Package love.forte.simbot.bot

Bot 相关定义，包含 Bot、BotManager、BotPlugin 等核心抽象。

# Package love.forte.simbot.bot.configuration

Bot 配置相关类型，如调度器配置、代理配置等。

# Package love.forte.simbot.component

组件抽象定义。

# Package love.forte.simbot.definition

定义类型，包含 Actor、User、Contact、Organization 等实体抽象。

# Package love.forte.simbot.event

事件系统定义，包含 Event、EventListener、EventDispatcher 等核心抽象。

# Package love.forte.simbot.message

消息定义，包含 Message、Messages、MessageContent 等消息相关抽象。

# Package love.forte.simbot.plugin

插件抽象定义。

# Package love.forte.simbot.resource

资源抽象定义。
